# 🛍️ EightyEight - Frontend E-Commerce Website

EightyEight ek modern aur responsive e-commerce frontend website hai jo **HTML, CSS, aur JavaScript** ka use karke banayi gayi hai. Yeh project UI/UX design aur frontend development skills ko showcase karta hai.

---

## 🚀 Features

* 🛒 Product Showcase Layout
* 🎨 Clean & Modern UI
* 📱 Fully Responsive Design
* ⚡ Smooth Animations
* 🔍 Interactive Elements (JS based)
* 🧭 Easy Navigation

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & Layout
* **JavaScript** – Interactivity
* **Bootstrap (optional)** – Responsive Design
